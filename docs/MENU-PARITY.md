# Menu parity — v1 (0.3.380) to the v2 combined menu

v1 locations are the ChEng AIO shell, the embedded Voyage Chief menu, and the embedded Tank Chief menu in `history/cheng-pro` at 0.3.380. In v2 the shell hides those module menus. Every destination below is one entry in the Windows sidebar and, unless noted, the same entry in the phone/tablet More sheet. The bottom bar stays Home, Noon, Soundings, e-ORB, More.

Status: **reachable** was already in the v2 shell. **added** is a new link in this change. **covered** is the same screen as another v2 entry, so it is not listed twice.
